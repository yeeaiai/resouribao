# 热搜日报

> 为你汇总 昨日热搜。

[打开热搜日报](https://resouribao.top/) · [GitHub Pages 备用地址](https://yeeaiai.github.io/resouribao/) · [腾讯云备用网址](https://resou-daily-d7gt62n4r0e605a2c-1341971865.tcloudbaseapp.com/)

每天都有大量话题在微博热搜里快速出现、变化、消失。**热搜日报**不试图罗列全部热搜，而是从一天的热搜记录中筛选、合并出十件更值得回看的事件与话题：它们既是昨天发生了什么，也是人们当时在讨论什么。

适合在早晨通勤、午休摸鱼，或想补一补“昨天大家都在聊什么”时，花几分钟扫一眼。

## 它如何工作

电脑保持开机和联网时，任务会在每个整点记录一次微博热搜。次日凌晨，系统汇总过去 24 小时的记录，识别同一事件的不同分支话题，再生成一份日报。

| 时间 | 自动完成的事 |
| --- | --- |
| 每个整点 | 记录微博热搜榜话题 |
| 00:05 | 汇总昨日话题、合并事件并生成日报 |
| 00:10 | 自动更新网站与历史日期页面 |

日报并不是按照某一个时刻的榜单顺序排列。排序会综合话题的最高热度、最高排名和持续出现情况，因此更接近“这一天里最有存在感的讨论”。

## 筛选规则

每天固定保留十条，并遵循以下原则：

1. **合并同一事件**：同一新闻或事件衍生出的多个话题，会整理为一个事件卡片，并保留“相关热搜”供查看。
2. **控制娱乐比例**：娱乐话题不超过三条，避免日报被单一类型内容占满。
3. **保留讨论的广度**：科技、财经、社会、国际等公共议题至少各保留一条，尽量呈现更完整的日常讨论面貌。
4. **剔除不适合的内容**：不收录商业营销热搜和政治宣传内容。

## 每条日报里有什么

- **昨日头条**：当天最值得关注的一件事。
- **更多热搜**：其余九条经过筛选的事件与话题。
- **相关热搜**：被合并的同一事件分支，让你知道这次讨论是如何展开的。
- **热搜表现**：话题的最高指数、出现次数与最高排名，用于理解它在当天热搜中的表现。
- **微博检索**：每条话题都保留微博检索入口，想继续看原始讨论可以直接跳转。
- **更多日期**：可回看已生成的历史日报。

简介的目标是帮助读者快速理解微博里正在讨论什么；需要进一步了解时，请以链接中的原始公开信息为准。

## 为什么做它

很多人已经不再频繁刷微博，但仍然会好奇：今天发生了什么？有哪些话题被广泛讨论？

这个项目最初只是一个每晚发给自己的本地脚本，已经稳定运行了一段时间。后来把它做成公开网页，希望让更多人能用更低的时间成本，留下一份可以回看的“昨日记录”。

## 关于这个仓库

这里是热搜日报的**公开静态发布仓库**：保存网站页面和日报归档，以便 GitHub Pages 对外展示。出于账号安全和平台使用规范考虑，微博采集脚本、登录状态、密钥与本地自动化配置均不在此仓库公开。

项目仍在持续调整：筛选与合并机制会根据实际日报效果不断优化。如果你发现错漏、排序不合理，或有任何建议，欢迎通过 GitHub 的 Issues 留言。

## 说明

- 本站依据公开微博热搜话题整理，不构成新闻报道、投资建议或事实认定。
- 热搜反映的是平台上的讨论热度，并不等同于事件的重要性、真实性或完整性。
- 页面中的相关链接跳转至微博公开检索页面；请遵守相应平台规则。
